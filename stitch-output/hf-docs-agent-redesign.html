What does save_pretrained save to disk?

🤗
HF Docs Assistant RAG v4.36 • 420ms cosine 0.94

save_pretrained() writes all necessary configuration and weight artifacts to reload the exact state of an instance using its matching from_pretrained() method.

The exact artifacts written depend on the class component being serialized:

PreTrainedModel (e.g., BertModel, GPT2LMHeadModel) weights & architecture
  • model.safetensors (default safe serialized weights) or pytorch_model.bin.
  • config.json — Model architecture metadata, hyperparameters, and tensor layer shapes.
  • generation_config.json — Optional inference sampling parameters (top_p, beam size, etc.).
PreTrainedTokenizer / PreTrainedTokenizerFast vocab & tokens
  • tokenizer.json — Full serialized Rust fast-tokenizer pipeline.
  • vocab.txt or vocab.json / merges.txt — Vocabulary tables.
  • tokenizer_config.json and special_tokens_map.json — Tokenizer rules and flags.
PEFT LoRA Adapters (PeftModel) delta matrices
  • adapter_model.safetensors — Low-rank weights (only trainable weights, not the base model).
  • adapter_config.json — Hyperparameters (r, lora_alpha, target_modules).
